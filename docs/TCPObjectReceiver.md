**TCPObjectReceiver** — WebSocket-сервер для приёма пакетов объектов от внешних клиентов (например, `TCPObjectTransmitter`) и их дальнейшей передачи в систему через стандартный выходной порт.

**Как работает**:  
Слушает указанный хост и порт, принимает соединения и JSON-сообщения в формате `{ _pkgIndex: N, objects: [...] }`. При получении валидного пакета:
- отправляет подтверждение (`{ _pkgIndex: N }`),
- каждый объект из `objects` поочерёдно выдаётся на выходной порт `object`,
- инкрементирует счётчик `recived`.

**Особенности**:
- Поддерживает механизм подтверждения доставки (reliable delivery),
- Не буферизует полученные данные — передаёт «на лету»,

**Типичное применение**:  
Централизованный приём данных от распределённых `ObjectSender` - устройств (например, с удалённых узлов сбора) в единую систему обработки.
