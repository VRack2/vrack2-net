Устройство для запуска HTTP-сервера статических файлов. 

Раздаёт содержимое указанной директории по заданному порту. Отслеживание статистики (количество запросов, статус работы) и автоматический определитель Content-Type для файлов. 

Включает защиту от выхода за пределы целевой директории. 

Используется для быстрого развёртывания веб-интерфейсов, дашбордов и статических ресурсов без внешних серверов.
